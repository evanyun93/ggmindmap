## 🗺️ 마인드맵 (Mind Canvas)

마인드맵은 **카드 위젯(미리보기)**과 **편집 모드** 두 가지로 나뉩니다.

### 📋 카드 위젯 (미리보기)
- 저장된 마인드맵을 대시보드에서 **읽기전용**으로 확인할 수 있습니다.
- **드래그**: 마인드맵 뷰 이동 (카드 자체는 이동되지 않음)
- **스크롤 / 핀치**: 확대 · 축소
- 카드 우측 상단의 **✏️ 편집 모드** 버튼을 눌러 편집 화면으로 진입합니다.

### ✏️ 편집 모드
편집 모드에서는 자유롭게 마인드맵을 그리고 수정할 수 있습니다.

#### 도형 그리기
| 동작 | 결과 |
|------|------|
| 빈 캔버스에서 **둥글게** 드래그 | 원(Circle) 생성 |
| 빈 캔버스에서 **각지게** 드래그 | 사각형(Rect) 생성 |
| 빈 캔버스에서 **세 변**을 그리듯 드래그 | 삼각형 생성 |

#### 노드 조작
| 동작 | 기능 |
|------|------|
| 노드 **드래그** | 위치 이동 |
| 노드 **더블클릭** | 이름 편집 |
| 노드 **우클릭** | 이름 변경 · 크기 조정 · 삭제 메뉴 |
| 도형 **테두리 드래그** | 크기 조절 (원·사각형·삼각형 전체 바운더리 인식) |

#### 노드 연결
- **Shift + 클릭**: 첫 번째 노드를 선택한 뒤, 두 번째 노드를 클릭하면 화살표로 연결됩니다.
- 연결선을 클릭하면 강조 표시됩니다.

#### 단축키
| 키 | 동작 |
|----|------|
| `Del` / `Backspace` | 선택된 노드 삭제 |
| `ESC` | 연결 모드 취소 · 크기 조정 취소 · 선택 해제 |
| `Enter` | 편집 완료 · 크기 조정 완료 |

#### 저장
- 상단 **저장** 버튼을 클릭하면 카드 위젯에도 즉시 반영됩니다.

## 💊 영양제 신호등 위젯

매일 먹는 영양제들을 등록하면, 영양소를 자동으로 합산해 **부족·적정·과다 여부를 신호등처럼 색으로** 보여주는 위젯입니다.

### 🔍 영양제 등록하기
- 위젯 상단의 `+ 영양제 추가` 버튼을 눌러 제품명을 검색하고, 영양제 목록에서 선택하면 자동으로 영양 성분이 불러와집니다.
- 등록된 영양제는 언제든지 삭제하거나 순서를 바꿀 수 있습니다.

### 🚦 신호등 색상 의미
| 색상 | 상태 | 의미 |
|------|------|------|
| 🔴 빨강 | 위험 | 안전 상한선(UL)을 초과했습니다. 복용량 조절이 필요합니다. |
| 🟠 주황 | 과다 | 권장량의 150% 이상이며, 지용성 비타민·미네랄처럼 몸에 쌓일 수 있습니다. |
| 🟡 노랑 | 초과 | 권장량을 넘었지만 위험 수준은 아닙니다. |
| 🟢 초록 | 적정 | 권장량의 50~100% 범위로 잘 먹고 있습니다. |
| 🔵 파랑 | 부족 | 권장량의 50% 미만입니다. 보충을 고려해보세요. |
| 🩵 청록 | 고용량 | 권장량의 150% 이상이지만, 수용성 비타민(B1 등)처럼 초과분이 몸에서 자연 배출됩니다. |

> 💡 **점선으로 표시된 항목**은 현재 먹고 있는 영양제에 없는 필수 영양소입니다. 0mg으로 표시되며, 보충이 필요한지 확인해보세요.

### 🤖 AI 분석 결과 보기
- `분석하기` 버튼을 누르면 AI가 내 영양제 조합을 살펴보고, 영양소 상태를 쉬운 말로 설명해줍니다.
- 분석 결과 상단의 뱃지로 **AI 분석** 여부를 확인할 수 있습니다.
  - `🤖 AI 분석` — AI가 직접 분석한 결과입니다.
  - `📊 기준 분석 ⓘ` — AI 대신 한국인 영양섭취기준(2020 DRI) 규칙으로 분석한 결과입니다. 버튼을 클릭하면 영양소별 상세 기준과 출처를 확인할 수 있습니다.

### 📌 알아두면 좋은 점
- 권장량은 **성별·나이** 기준으로 자동 적용됩니다. 내 프로필 설정이 정확할수록 더 정확한 분석이 가능합니다.
- **임신 중이라면** 설정 → 건강 정보에서 임신 여부를 체크해주세요. 엽산, 철분, 오메가3 등 임신 중 권장량이 높아지는 영양소를 별도 기준으로 분석하며, AI 코멘트에도 임신 상태가 반영됩니다.
- 비타민 B6는 장기 과다 복용 시 신경 이상이 생길 수 있어, 고용량이더라도 "과다"로 표시됩니다.

> ⚠️ **주의사항**: 본 분석은 한국인 영양섭취기준(2020 DRI) 및 AI를 활용한 **참고용 정보**입니다. 의학적 진단·치료를 대체하지 않으며, 건강 관련 중요한 결정은 반드시 의사 또는 전문 영양사와 상담하시기 바랍니다.
