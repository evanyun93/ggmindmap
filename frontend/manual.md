## 📑 화면 레이아웃 관리 (New!)

- **나만의 화면 저장**: 좌측 상단의 `+ 새 화면 저장` 버튼으로 현재 위젯 배치를 새로운 탭으로 저장할 수 있습니다. (최대 5개)
- **자유로운 전환**: 상단에 나열된 아이콘 탭을 클릭하여 저장된 서로 다른 배치로 즉시 전환하세요.
- **실시간 자동 저장**: 위젯을 옮기거나 크기를 조절하면, **현재 보고 있는 탭에 즉시 자동 저장**됩니다. 따로 저장 버튼을 누를 필요가 없습니다!
- **크로스 플랫폼**: PC에서 설정한 탭 목록은 모바일에서도 그대로 유지되며, 배치는 각 기기 화면에 맞게 독립적으로 관리됩니다.

## 🗺️ 마인드맵 (Mind Canvas)

마인드맵은 **카드 위젯(미리보기)**과 **편집 모드** 두 가지로 나뉩니다.

### 📋 카드 위젯 (미리보기)
- 저장된 마인드맵을 대시보드에서 **읽기전용**으로 확인할 수 있습니다.
- **드래그**: 마인드맵 뷰 이동 (카드 자체는 이동되지 않음)
- **스크롤 / 핀치**: 확대 · 축소
- 카드 우측 상단의 **✏️ 편집 모드** 버튼을 눌러 편집 화면으로 진입합니다.

### ✏️ 편집 모드
편집 모드에서는 자유롭게 마인드맵을 그리고 수정할 수 있습니다.

#### 도형 그리기
| 동작 | 결과 |
|------|------|
| 빈 캔버스에서 **둥글게** 드래그 | 원(Circle) 생성 |
| 빈 캔버스에서 **각지게** 드래그 | 사각형(Rect) 생성 |
| 빈 캔버스에서 **세 변**을 그리듯 드래그 | 삼각형 생성 |

#### 노드 조작
| 동작 | 기능 |
|------|------|
| 노드 **드래그** | 위치 이동 |
| 노드 **더블클릭** | 이름 편집 |
| 노드 **우클릭** | 이름 변경 · 크기 조정 · 삭제 메뉴 |
| 도형 **테두리 드래그** | 크기 조절 (원·사각형·삼각형 전체 바운더리 인식) |

#### 노드 연결
- **Shift + 클릭**: 첫 번째 노드를 선택한 뒤, 두 번째 노드를 클릭하면 화살표로 연결됩니다.
- 연결선을 클릭하면 강조 표시됩니다.

#### 단축키
| 키 | 동작 |
|----|------|
| `Del` / `Backspace` | 선택된 노드 삭제 |
| `ESC` | 연결 모드 취소 · 크기 조정 취소 · 선택 해제 |
| `Enter` | 편집 완료 · 크기 조정 완료 |

#### 저장
- 상단 **저장** 버튼을 클릭하면 카드 위젯에도 즉시 반영됩니다.

## 💡 기타 꿀팁

- 각 카드는 우측 상단의 **∨ 토글**로 접기/펼치기
- **카드 이동** 시에는 접기/펼치기 버튼이 눌리지 않음
- 각 카드의 크기는 우측하단 꼭지점으로 크기 조절 가능
